# Szonszczyk - Caliber Split Magazine Cases

Server mod for Single Player Tarkov that is adding magazine cases that are split by caliber. Choose your size and add them to one of 5 different trader settings. All mods compatible!

## Compatibility with SPT versions

3.11.* - current version  
3.10.* - change version in package.json and it will work  
3.9.* - not checked, but should work
